# 真人四场试玩清单

目的：验证“人实际操作一整局”是否顺畅。自动测试已经覆盖规则状态，但无法判断按钮是否好找、等待是否令人困惑、日志是否看得懂。

## 开始前

1. 双击项目根目录的 `启动本地原型.cmd`。
2. 浏览器打开 `http://127.0.0.1:3100`。
3. 创建房间，再点击“新窗口模拟朋友”。
4. 第二个窗口输入另一个昵称和房间码加入。
5. 两个窗口分别代表两名玩家；不要在同一个窗口操作两个座位。

三人测试时再打开一个新窗口。第一轮建议先完成两人局，以减少等待和记录负担。

## 必走流程

完成以下项目时勾选：

- [ ] 创建房间后，房间码清楚可见。
- [ ] 另一窗口加入后，两个窗口都能看到正确玩家名单。
- [ ] 非房主看不到开始按钮或无法开始。
- [ ] 开始后，每个窗口只看到自己的四张手牌。
- [ ] 一方选择角色后，另一方看不到具体选择。
- [ ] 两方都选好后，角色同时公开并进入赛道。
- [ ] 当前玩家容易看出“轮到谁”。
- [ ] 掷骰后，保留、重掷或角色能力选择容易理解。
- [ ] 摔倒、加减速、额外移动能从事件日志中看懂原因。
- [ ] 第一名出现后比赛继续，第二名出现后立即结束。
- [ ] 两个玩家都确认后才进入下一场。
- [ ] 四场中角色不能重复使用。
- [ ] 特殊赛道的星星、箭头和摔倒格容易识别。
- [ ] 第四场结束后总分和并列结果显示正确。
- [ ] 页面刷新后仍恢复自己的座位和当前状态。

## 问题记录模板

发现问题时尽量记录以下信息，不需要写技术细节：

```text
发生在：第几场、第几个回合
两名角色：
操作前位置：
掷骰结果：
我点击了：
我预期：
实际发生：
页面提示／日志：
刷新后是否仍存在：
```

若方便，可同时截图赛道和“赛场速递”。不要复制或分享 `data/rooms.json`，其中包含本地座位凭证。

## 试玩后只需回答五件事

1. 是否完整玩完四场？若没有，停在哪里？
2. 哪一步最不清楚？
3. 哪个角色最容易误解？
4. 是否出现结果与你理解的规则不同？
5. 是否愿意再玩一局？若不愿意，主要原因是什么？

## 通过标准

两人完整四场无阻塞；没有需要刷新或重启才能继续的步骤；所有影响结果的问题均可复现并增加自动测试；修复后 29 项现有测试及新增测试全部通过。
