# 奇趣竞速 · 本地规则原型

用于验证《胡闹运动会》部分角色机制的本地开发原型。不是官方数字版，不公开发布。

新账户或新开发者请从 [START_HERE.md](START_HERE.md) 开始；自动化开发约束见 [AGENTS.md](AGENTS.md)。

当前支持 **2—3 人、12 个角色、四场比赛、秘密选角、技能选择、积分结算、同机多窗口同步和刷新恢复**。

## 启动与试玩

需要 Node.js 22 或以上，无需安装第三方依赖。

```text
node server.mjs
```

打开 <http://127.0.0.1:3100>。输入昵称创建房间，点击“新窗口模拟朋友”，在新窗口输入另一个昵称加入。两个窗口分别控制两个玩家；房主点击开始。

Windows 也可以双击 `启动本地原型.cmd`。如果服务已启动，直接打开上述地址即可。停止服务时关闭运行窗口，或在该窗口按 Ctrl+C。

启动窗口中的提示使用英文，以避免 Windows 批处理程序在部分中文编码环境中启动失败；游戏页面仍为中文。如果窗口显示 `Node.js was not found`，需要安装 Node.js 22 或以上。如果显示 `EADDRINUSE`，说明 3100 端口已有一个游戏服务在运行，可先直接打开网页地址。

**这是本地地址，只在运行服务的这台电脑可用。它不是可以发给异地朋友的联网地址。** 当前不进行外网部署；分享或移植前先处理授权，并完成真人试玩。

## 当前简化

- 角色先随机分发，暂不做蛇形选秀。
- 两人同样每人控制一名选手，暂不实现实体版双角色变体。
- 赛道、特殊格、奖分均为测试参数，界面已标明。
- 用户已指定：只剩兔子无法完赛时，递补第二名。
- 暂无自动托管、踢人、观战、微信登录或公开房间列表。

## 测试

```text
node --test
```

包含角色边界、500 局完整随机对局、房间权限、并发、操作去重、持久化失败回滚、服务重启与 HTTP 流程。

## 结构

- `lib/game.mjs`：独立规则状态机，可在移植时复用。
- `lib/rooms.mjs`：身份、操作版本、去重、串行事务与保存。
- `server.mjs`：本机 HTTP 服务，骰子由服务端产生。
- `public/`：手机宽度适配的网页界面和角色配置。
- `tests/`：自动测试。
- `data/rooms.json`：运行后生成的本机房间存档，包含座位凭证，不要分享。

房间状态自动保存。刷新同一标签页会恢复身份；主动“离开此座位”会清除该标签页的凭证，无法仅凭昵称找回。原型没有自动代打，离开的玩家会阻塞正在进行的比赛。

测试结果不意味着绝对零 bug；正式移植与公开使用尚未开始。
